# Data Room Checklist (Due Diligence Preparation)

## Corporate Documents
- [ ] Certificate of Incorporation
- [ ] Bylaws / Operating Agreement
- [ ] Board resolutions
- [ ] Cap table (current)
- [ ] Previous funding documents (SAFEs, convertible notes)
- [ ] Founders' Agreement

## Financial Documents
- [ ] Financial model (3–5 year projections)
- [ ] Monthly P&L (since inception)
- [ ] Bank statements (last 6 months)
- [ ] Revenue breakdown by customer
- [ ] Burn rate analysis

## Product & Technology
- [ ] Product demo / walkthrough video
- [ ] Architecture overview diagram
- [ ] Technology stack summary
- [ ] IP documentation (patents filed, if any)
- [ ] Security whitepaper

## Market & Customers
- [ ] Market sizing analysis
- [ ] Competitor analysis
- [ ] Customer list with logos (with permission)
- [ ] Case studies / testimonials
- [ ] Pipeline of prospective customers
- [ ] Letters of Intent (LOIs) from interested customers

## Team
- [ ] Founder bios and LinkedIn profiles
- [ ] Org chart
- [ ] Key hire plan
- [ ] Advisor agreements
- [ ] Employee option pool details

## Legal
- [ ] IP assignment agreements (all founders/employees)
- [ ] Customer contracts (template)
- [ ] Terms of Service
- [ ] Privacy Policy
- [ ] Any pending or threatened litigation (hopefully none)
- [ ] Insurance policies

## Organize in a Virtual Data Room
- Use: Google Drive (free), DocSend (paid), or Notion
- Share view-only links with tracking
- Organize by category (folders matching above)
