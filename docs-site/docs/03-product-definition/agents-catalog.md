# Division 2: HR Business Partners (HRBP)

## What HRBPs Do
HRBPs are **strategic advisors embedded in business units** who translate business needs into people strategy. They sit at the intersection of business and HR, working directly with leaders.

## HRBP Agent
**Replaces:** HR Business Partner ($90K–$150K)
**Mode:** **HYBRID** — agent handles 60-70% (analysis, recommendations, preparation, execution of routine items), human handles 30-40% (sensitive conversations, final strategic decisions, relationship building)

### What the Agent Handles (60-70%)
- Analyze business unit workforce data and surface insights to managers
- Prepare workforce planning recommendations (headcount, skills gaps, succession)
- Draft talking points and recommendations for manager 1:1s
- Generate organizational health reports per business unit
- Model scenarios: "What happens if we restructure team X?"
- Track and analyze team-level engagement, performance, and retention metrics
- Prepare talent review materials (9-box, succession pipelines)
- Provide managers with real-time coaching prompts and suggestions
- Execute approved HR actions (process promotions, transfers, comp changes)
- Surface early warning signals (attrition risk, engagement drops, performance trends)
- Benchmark business unit HR metrics against internal and industry standards
- Prepare board and leadership people reports for business units

### What Requires Human (30-40%)
- Sensitive employee relations conversations (terminations, grievances, investigations)
- Coaching senior leaders through complex organizational changes
- Navigating political dynamics and relationship building
- Final approval on strategic workforce decisions
- Facilitating difficult team dynamics
- Executive-level presentations and influence

### HRBP Agent KPIs
- Insights delivered per business unit per month
- Manager adoption rate of recommendations
- Time saved for managers on people decisions
- Business unit employee engagement scores
- Escalation quality (correct routing, appropriate escalation)

### Escalation Rules
- Harassment, discrimination, or legal claims → immediate human + legal
- Termination decisions → always human-in-the-loop
- Organizational restructuring → human approves, agent executes
- Sensitive interpersonal conflicts → human handles directly

# Division 5: Agent Factory

## What the Agent Factory Does
The Agent Factory is the **workforce composition division** within HR. When a company needs to fill a role, the Agent Factory analyzes the job description and decides: **should this role be a human or a virtual employee?** If an agent can do the job, the factory deploys one. If not, it routes the role to recruiting.

This is a new HR function that doesn't exist in traditional organizations — it's what makes an AI HR department fundamentally different.

## Agent Factory Engine

### How It Works
```
INPUT: Job Description (any role the company wants to fill)
  ↓
STEP 1: Parse the JD into structured components
  - Core responsibilities and daily tasks
  - Required skills and judgment level
  - Human interaction requirements (internal, external, sensitive)
  - Decision-making authority
  - Creative vs. process-driven work ratio
  - Regulatory/legal implications
  ↓
STEP 2: Score each dimension on an "AI Readiness" scale
  - Task repeatability:        [Low ←──→ High]
  - Rule-based vs. judgment:   [Judgment ←──→ Rule-based]
  - Human empathy required:    [High ←──→ Low]
  - Data availability:         [Low ←──→ High]
  - Error tolerance:           [Zero ←──→ Flexible]
  - Compliance sensitivity:    [High ←──→ Low]
  ↓
STEP 3: Generate recommendation
  - 🟢 FULL AGENT: AI agent can do 90%+ of this role → Deploy virtual employee
  - 🟡 HYBRID: AI agent can handle 50-90% → Deploy agent + human oversight
  - 🔴 HUMAN NEEDED: Role requires >50% human judgment → Route to Recruitment Ops
  ↓
STEP 4: Configure and deploy (if agent)
  - Create virtual employee profile (name, role, team, KPIs)
  - Connect to relevant systems and communication channels
  - Set escalation rules and human oversight parameters
  - Deploy to the customer's workspace
```

### Example Decisions

| Job Description Submitted | Factory Decision | Outcome |
|--------------------------|:----------------:|---------|
| HR Coordinator | 🟢 Agent | Deploy Employee Services Agent |
| Payroll Specialist | 🟢 Agent | Deploy Payroll Ops Agent |
| Executive Secretary | 🟢 Agent | Deploy virtual secretary |
| Financial Analyst | 🟢 Agent | Deploy virtual financial analyst |
| Market Researcher | 🟢 Agent | Deploy virtual market researcher |
| Data Entry Clerk | 🟢 Agent | Deploy virtual data processor |
| Content Writer | 🟡 Hybrid | Agent drafts + human creative direction |
| HR Business Partner | 🟡 Hybrid | Agent handles 60-70%, human handles sensitive work |
| Sales Account Executive | 🔴 Human | Route to Recruitment Ops Agent |
| Therapist / Counselor | 🔴 Human | Route to Recruitment Ops Agent |

### Agent Factory Dashboard
- View all roles analyzed with human/agent recommendations
- See deployed virtual employees by team and department
- Track cost savings: virtual employee cost vs. human equivalent
- Workforce composition: % human vs. % AI by department

### Data Flywheel
Every JD analyzed makes the factory smarter:
- Builds proprietary dataset of "what can be automated"
- Improves accuracy of human-vs-agent recommendations
- Identifies new agent templates to build
- Benchmarks across industries, company sizes, and role types

# How the Divisions Work Together

```
EXAMPLE: A new employee joins the company

CoE (designed the process)
  → Talent Acquisition CoE defined the hiring framework
  → Compensation CoE set the salary bands
  → L&D CoE designed the onboarding curriculum
  → Compliance CoE ensured the offer letter is compliant

Agent Factory (decided human vs. agent)
  → Manager submitted a JD for the role
  → Factory analyzed it and recommended: hire a human
  → Routed to Recruitment Ops

HRBP (strategic oversight)
  → HRBP Agent identified the headcount need with the business unit leader
  → Approved the role and compensation level

Analytics & Finance (informed the decisions + tracked costs)
  → Predicted the team needs a new hire based on workload data
  → Benchmarked the compensation against market
  → Modeled the fully-loaded cost before approval
  → Updated the department budget

Shared Services (executed the work)
  → Recruitment Ops Agent screened candidates and scheduled interviews
  → Employee Services Agent answered the new hire's pre-start questions
  → Onboarding Ops Agent collected documents and set up day-1
  → Payroll Ops Agent processed the first paycheck
```
