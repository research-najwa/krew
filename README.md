# HR AI Startup — Project Planning Hub

## The Idea
Build an AI-native HR company that encapsulates all HR practices and business-as-usual in AI agents. Companies subscribe to our agents instead of building or outsourcing an HR department.

## Immediate Next Steps
1. **Validate the idea** — Conduct 20+ customer discovery interviews
2. **Choose a name** — Check domain availability, register
3. **Build the founding team** — Find co-founder(s) if needed
4. **Build a prototype** — Start with the Employee Relations Agent
5. **Create the pitch deck** — Prepare for fundraising
6. **Decide on geography** — Where to launch first?
