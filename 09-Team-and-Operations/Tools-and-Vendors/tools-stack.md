# Internal Tools & Vendor Stack

## Day-to-Day Operations
| Category | Tool | Cost/Month |
|----------|------|-----------|
| Communication | Slack | Free–$8/user |
| Email | Google Workspace | $6/user |
| Project Management | Linear or Notion | $8–$10/user |
| Documentation | Notion | Included above |
| Design | Figma | $12–$15/user |
