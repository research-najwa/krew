# Website Plan

## Purpose
Convert visitors into waitlist signups (pre-launch) and trial signups (post-launch).

## Pages Needed

### 1. Homepage
- Hero: Headline + subheadline + CTA ("Get Started" / "Join Waitlist")
- Problem section: "HR is broken" (3 pain points)
- Solution section: "Meet your AI HR team" (agent overview)
- How it works: 3-step visual
- Social proof: Customer logos, testimonials, metrics
- Pricing preview: 3 tiers with CTA
- FAQ section
- Footer CTA

### 2. Product / Agents Page
- Overview of all 10 agents
- Click into each agent for detailed capabilities
- Screenshots / demo videos
- Integration logos

### 3. Pricing Page
- 3-tier comparison table
- FAQ about pricing
- "Talk to sales" for Enterprise
- ROI calculator (interactive)

### 4. About Page
- Mission and story
- Team photos and bios
- Values
- Careers link

### 5. Blog
- SEO-optimized articles
- Categorized by topic (AI, HR, Compliance, Product Updates)

### 6. Contact / Demo Request
- Form for demo requests
- Calendar embed for booking

## Tech Stack for Website
- **Framework:** Next.js (React)
- **Hosting:** Vercel
- **CMS for blog:** Contentful, Sanity, or MDX
- **Analytics:** PostHog or Mixpanel
- **Forms:** Built-in or Typeform
- **Chat widget:** Intercom or Crisp

## Timeline
- [ ] Pre-launch: Simple landing page with waitlist (Week 1)
- [ ] Launch: Full website with all pages (Month 5–6)
- [ ] Post-launch: Blog content engine running weekly
